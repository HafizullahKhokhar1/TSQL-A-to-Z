# Contributing

Thanks for helping improve T-SQL A to Z.

## Before You Start
- Read [docs/SETUP.md](docs/SETUP.md) and [docs/STYLE_GUIDE.md](docs/STYLE_GUIDE.md).
- Follow the learning path in [docs/LEARNING_PATH.md](docs/LEARNING_PATH.md).
- Keep scripts safe to run on a clean learning database.

## Workflow
1. Open an issue or pick an existing lesson improvement.
2. Make focused changes in one topic area.
3. Test the script in SQL Server Management Studio.
4. Update docs if the lesson flow changes.
5. Submit a pull request using the template in `.github/pull_request_template.md`.

## Writing Rules
- Prefer clear comments over clever SQL.
- Keep examples realistic and small.
- Drop and recreate sample objects in lesson scripts when needed.
- Use the database name `TSQL_A_TO_Z` consistently.

## Review Notes
Pull requests are easier to review when they stay narrowly scoped and include a short note about what the learner will practice.
