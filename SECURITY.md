# Security Policy

This repository is educational and does not process production data.

## Supported Content
- Lesson scripts
- Practice exercises
- Repository documentation

## Reporting a Problem
If you find a security issue in the repository content, open a private report or a confidential issue if your GitHub settings support it.

## Safe Usage Notes
- Review scripts before running them.
- Run the lessons in a non-production SQL Server instance.
- Use a dedicated learning database such as `TSQL_A_TO_Z`.
